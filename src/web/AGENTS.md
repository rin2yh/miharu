# Reactフロントエンドのルール

- React Compilerを有効にしているため、`useMemo`、`useCallback`、`React.memo` などの手動メモ化は原則使わず、通常の式・関数・コンポーネントとして記述する。
- 参照の安定性がAPI契約などの意味的な要件になる場合に限り、手動メモ化を例外として使える。その場合は、近くに必要な理由を記載する。
- `useState`、`useRef`、`useEffect` など、状態管理や副作用のためのHookは用途に応じて使う。手動メモ化の方針をこれらへ広げない。
- React Hooksの規則に従い、依存配列を含めたEffectの実行タイミングをLintとテストで確認する。
